# v0.2 协议边界测试计划

## 语义摘要

llm4cj 0.2 将协议 envelope、provider dialect、模型能力和传输状态分开。测试只通过 public API 检查 request plan、固定响应终态、增量事件、SSE framing、错误分类和 native replay。

## 控制流路径

| Path ID | 条件 | 可观察结果 |
| --- | --- | --- |
| P001 | built-in dialect 的最小合法请求 | 输出精确 body、headers 和 requirements |
| P002 | 显式功能有对应 contract 与能力 | dialect 输出精确字段 |
| P003 | 显式功能缺少能力或 dialect 无法表示 | 抛出 `Unsupported` |
| P004 | strict 工具历史合法 | 保持原顺序编码 |
| P005 | strict 工具历史孤立、重复或未来匹配 | 抛出 `InvalidRequest` |
| P006 | strict 工具历史在结尾仍有 pending call | 抛出 `InvalidRequest` |
| P007 | 固定响应处于 pending、success、incomplete 或 failed | 返回对应 `LlmWireResponseState` |
| P008 | 已知字段类型错误、缺失或溢出 | 抛出 `InvalidWire` |
| P009 | 完整工具参数为对象、非对象或非法 JSON | 返回 Complete、InvalidShape 或 InvalidJson |
| P010 | native replay 完整且 protocol、dialect、model 和顺序相同 | 原始 payload 可重放 |
| P011 | display reasoning、partial 或不兼容 native replay | 抛出 `Unsupported` |
| P012 | 流事件按协议索引交错到达 | delta 保留完整身份并正确聚合 |
| P013 | Chat choice finish 后收到 usage-only 尾块 | 接受 usage，直到 DONE 或合法 EOF 才 terminal |
| P014 | EOF 缺少语义终态或 terminal 后再有语义事件 | 抛出 `InvalidWire` |
| P015 | decoder 首次失败、重复 finish 或关闭后 push | 后续调用返回稳定 failed/closed 错误 |
| P016 | SSE 使用 CR、LF、CRLF、BOM、空 data 和分片 UTF-8 | 只在空行派发规范事件 |
| P017 | SSE EOF 有未完成事件 | 丢弃尾部事件 |
| P018 | SSE event、line、retained bytes 或单次事件数超限 | 返回 `LimitExceeded` 并进入 Failed |
| P019 | Retry-After 为秒、三种 HTTP 日期、重复值或非法值 | 返回精确 `Some`、最大合法值或 `None` |
| P020 | provider error body 或 stream event | 返回 `Failed` 并保留 provider type、code 和 message |
| P021 | Responses tool delta 只携带 item ID | 从先前 item start 恢复 call ID/name；未知或 index 变化则失败 |
| P022 | 任意字节边界切分同一 SSE event | 输出与未切分输入完全一致 |
| P023 | DeepSeek Chat reasoning 参与工具续轮 | reasoning/content/tool calls 保持同一 assistant message 且限制同 dialect 回放 |
| P024 | tool calls 尚未全部闭合时出现普通内容或下一轮 | 编码前抛出 `InvalidRequest` |
| P025 | 固定或流式响应出现未知语义 block/event | 抛出 `Unsupported` 并携带有界诊断，不返回成功 |
| P026 | 固定和流式输入表达同一响应 | 共享 final assembler 并生成等价 canonical reply |
| P027 | usage update 是 replace、monotonic 或 delta | 按 dialect contract 合并，拒绝 monotonic 回退与负增量 |
| P028 | stream 截断、cancel、deadline 或 transport failure | 保持独立错误 kind、phase 与协议上下文 |
| P029 | public identity enum 被调用方比较 | 每个 variant 通过 `std.deriving.Equatable` 提供稳定判等 |
| P030 | custom contract 声明无 encoder 映射或冒用内置 ID | 构造阶段拒绝，不产生 silent no-op |
| P031 | NativeReplay type/schema/scope 不在 dialect allowlist | restore 返回 `Unsupported` 或 `InvalidWire` |
| P032 | Messages 多次 message_delta、stop reason 与 block index | 累计 usage、stop 稳定、index 连续 |
| P033 | Chat tool arguments 早于完整 identity | 有界缓冲，先 start 再发原序 delta |
| P034 | Responses created/in-progress 与 item/content lifecycle | start 一次；delta/done/terminal identity 一致 |
| P035 | done-only、terminal-only 或 retained state 超限 | `LimitExceeded` 且 decoder poisoned |
| P036 | SSE retry 含额外空白或 RFC850 跨世纪 | retry 忽略；年份相对显式 now 应用 50 年规则 |
